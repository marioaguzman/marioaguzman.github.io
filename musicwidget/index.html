Music Widget

A mini player remote for Apple Music. A take on the classic iTunes widget.

Basic Controls

Music Widget has the same playback and volume controls as the original iTunes Dashboard Widget. It also has the same keyboard shortcuts as the Music app so there is nothing new for you to learn!

Playlists

Just like the original, Music Widget performs a beautiful and fluid flip animation to reveal the Playlist chooser. Simply click the Inspector button to get started.

Live Streaming UI

If you love streaming live audio like Apple Music One or other live stations like CNN, Music Widget displays a UI designed specifically for streaming audio.

Craftsmanship

A fully native AppKit app, Music Widget is both lightweight and snappy. The User Interface leans heavily on Core Graphics & Core Animation0 in order to achieve crisp details for both Retina & non-Retina displays.

Specs and Requirements

Software macOS Monterey and newer; Music.app
Hardware Universal Binary for Macintosh computers with Apple Silicon and Intel processors
Language English, Spanish, Italian, Finnish, German, and Polish
Code 100% Native. Written in Swift & Objective-C using AppKit.
